# 首页城市公开课频道视觉改造设计

## 背景

首页当前使用 `CityChannelCard` 展示城市频道入口，视觉为简单网格卡片。目标是改成参考图中的“城市公开课频道”模块：突出上海、深圳、广州三座重点城市，并用项目内已准备好的城市切图增强识别度。

## 范围

- 仅改 C 端首页城市频道模块。
- 保留现有首页数据入口：`getActiveCities(18)`。
- 复用现有城市跳转路径：`cityChannelPath(enName)`。
- 使用现有图片资源，统一从 `/statics/images/city/` 读取：
  - `/statics/images/city/城市名片，上海.png`
  - `/statics/images/city/城市名片，深圳.png`
  - `/statics/images/city/城市名片，广州.png`
  - `/statics/images/city/*.png`

## 视觉结构

1. 顶部标题区：
   - 主标题：`城市公开课频道`
   - 副标题：`发现本地热门培训资源，快速查看近期公开课安排`
   - 右侧胶囊按钮：`定位：上海`、`查看全部城市`

2. 筛选条：
   - 展示 `热门城市`、`附近城市`、`生产管理`、`质量管理`、`本月开课`
   - 本次先实现为静态视觉入口，不引入筛选状态和数据请求。

3. 重点城市：
   - 固定优先展示上海、深圳、广州。
   - 三张大卡使用重点城市 PNG 作为背景。
   - 课程数优先来自后端 `courseCount`，没有数据时使用兜底数字。
   - 展示热门分类、本月开课、查看课程入口。

4. 小城市网格：
   - 展示苏州、北京、杭州、西安、武汉、成都、青岛、嘉兴、合肥、长沙、昆明、重庆等城市。
   - 图片来自 `/statics/images/city/` 目录。
   - 每张卡包含城市图标、城市名、课程数、查看课程入口。

5. 底部需求 CTA：
   - 文案：`没有找到合适课程？发布培训需求，获取本地培训方案`
   - 主按钮跳转 `/publish-demand`
   - 展示三个卖点：专业顾问对接、精准匹配课程、快速响应需求。

## 组件与数据

- 主要修改 `frontend/src/features/city/components/CityChannelCard.tsx`。
- 可在同文件内维护城市图片映射和兜底展示数据，所有城市图片路径统一指向 `/statics/images/city/`，避免实现中依赖中文目录名。
- 若后端未返回某个展示城市，用兜底城市项保证视觉完整。
- 不改 `CityChannelSection`、城市详情页或后端接口。

## 响应式

- 桌面端：三张重点城市横向三列，小城市六列网格。
- 平板端：重点城市两列或单列，小城市三列。
- 移动端：标题按钮换行，筛选条横向滚动，重点城市单列，小城市两列。
- 文字不得溢出卡片，按钮和卡片尺寸保持稳定。

## 验证

- 使用 `pnpm lint` 验证前端代码。
- 如本地 dev server 可用，打开首页检查桌面和移动端截图，确认图片加载、布局不重叠、链接可点击。
