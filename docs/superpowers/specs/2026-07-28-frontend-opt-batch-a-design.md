**日期**：2026-07-28  
**来源**：`docs/tmp/待优化记录.pdf` 条目 3、5、6、9、10–14  
**范围**：仅 `frontend/`（C 端）  
**策略**：按页面点状修补（方案 1），不抽共享抽象、不改后端契约  

## 1. 目标与非目标

### 目标

落实 PDF Batch A 中已对齐的前端体验问题：筛选即时生效并关浮层、首页专家大卡简介铺满、常驻城市文案、顶栏产品外链、专家评价/Tab 滚动体验、视频播放器中文与布局、视频分类只保留一级。

### 非目标（本批不做）

- 301 / 城市分站 / SEO URL 一致性（Batch C）
- 客服弹窗、登录协议、智能客服卡片（Batch B）
- 上海/北京性能、图片必填、Win11 全局 DPI/rem（Batch D）
- 专家详情改为「单页堆齐所有模块 + scroll-spy」（明确降级，见 §3.5）

## 3. 设计细节

### 3.1 筛选浮层（#3）

**落点**：`TrainerFilters.tsx`；公开课/内训同源侧栏若同样「点选后浮层不关」，一并改。

**行为**：

1. 选项 `onClick` → 调用现有 `onChange`（写查询/URL）。
2. 随后 `setActiveFilter(null)` 关闭浮层。
3. 若存在「确认」按钮则移除（当前专家侧栏无确认按钮，以关浮层为主）。

### 3.2 首页专家大卡（#5）

**落点**：`ExpertsSection.tsx` → `MainExpertCard`。

**行为**：

- 去掉或显著放宽 bio 的 `line-clamp-6`。
- bio 容器使用 `flex-1`（或等效）占满副标题与底部标签区之间的空间。
- 标签 +「查看专家详情」保持 `mt-auto` 贴底。
- 模块总高 `md:h-[500px]` 本批不改。

### 3.3 常驻城市文案（#6）

**落点**：`TrainerFilters.tsx` 展示 label、`messages/zh-CN/trainer.json` 等用户可见文案。

**行为**：展示「常驻城市」。注释/类型说明可同步用词；接口 `region` / `provinceId` 不变。

- 外链：`target="_blank"` + `rel="noopener noreferrer"`。

### 3.5 专家详情 Tab / 评价（#10、#11）

**落点**：`TrainerDetailTabs`、`TrainerDetailContent` / `ReviewsView`（「我要评价」）。

**架构约束**：现状为路由切换 Tab（每次只渲染一块内容），非单页长滚动。本批**不**改为 scroll-spy 单页。

**#11**：

- 保留 `getTrainerDetailTabHref` SEO 路径与下划线选中。
- 点击/进入 Tab 后，平滑滚动到内容区顶部；内容区设置 `scroll-margin-top`（或等价 offset），避免被 sticky 顶栏遮挡。
- 新的滚动可中断上一次滚动。

**#10**：

- 进入学员评价 Tab（含 `.../comment.htm`）后，将「我要评价」按钮滚到视口垂直中线附近（扣 sticky 顶栏高度）。

### 3.6 视频播放页（#12、#13、#14）

**落点**：

- #12：`VideoJsPlayer.tsx` + `video-player.css`（及 language 配置若有）。
- #13：`VideoPlayPageContent.tsx`（及播放页外层布局）。
- #14：`VideoPlayPageContent.tsx` → `categoryTags`。

**#12**：Fullscreen 等控件文案中文化；全屏按钮保持控制条右下。

**#13**：主内容列 `max-width` + 水平居中，浏览器约 150% 缩放时左右留白接近对称。

**#14**：`categoryTags` 只保留第一个标签（优先 `categoryName`）；去掉二级分类与 keywords 衍生标签。

## 4. 数据流与错误处理

- 筛选仍走现有 URL/查询同步；无新 API。
- 顶栏外链失败由浏览器处理；不增加前端错误提示。
- 评价/Tab 滚动仅在客户端、元素存在时执行；元素未挂载则跳过，不 toast。
- Video.js 语言包不全时，用 CSS/`controlBar` 文案补齐可见英文。

## 6. 风险

- #11 与 PDF「单页滚动到各模块」理想态有差距；已与产品对齐为本批降级方案。
- 顶栏第三方链接可达性不在本批保障范围。
- Video.js 默认英文控件需显式语言/文案覆盖，存在漏网词条风险，验收时扫一遍控制条。
