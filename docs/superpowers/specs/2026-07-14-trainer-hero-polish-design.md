## 1. 背景与目标

对齐改版落地后，用户批注仍要求：

1. 红白分界线继续右移（红更宽）。  
2. 姓名/头衔字号略放大。  
3. 姓名 + 标签 + 统计整体落在**白色区域**内，不压红底。  
4. 累计咨询 / 累计曝光数字略放大。  
5. 底部白色装饰随分界同步右移，显示在照片下方一带。

策略沿用 **方案 A（加间距进白区）+ 中幅位移 B + 实现方案 1**。

---

## 2. 用户决策

| 项 | 选择 |
|----|------|
| 进白区方式 | **A**：红界右移 + 加大照片与文案间距，信息整体右移进白区 |
| 位移量级 | **B 中幅**：约 +80–100px（实现取 **96px**） |
| 实现 | **方案 1**：调 calc 余量 + `ml-*` + 字号；底白装饰同步 |

---

## 3. 具体改动（仅 `TrainerHero.tsx`）

| 项 | 现状 | 目标 |
|----|------|------|
| 红区 calc 末项余量 | `50px` | **`96px`** → `w-[calc((100%-min(100%,1400px))/2+24px+225px+96px)]` |
| 照片→信息间距 | `ml-6`（24px） | **`ml-24`（96px）** |
| 姓名 | `text-[30px]` | **`text-[34px]`** |
| 头衔 | `text-[12.5px]` | **`text-[14px]`** |
| 咨询/曝光数字 | `text-[17px]` | **`text-[20px]`** |
| 底白装饰 | decor 随带宽变化；可能不足 | 优先 `object-position`；不足则在红区右下加小白装饰层，水平偏移与余量增量一致（约 **+46px**） |

**不变**：`max-w-[1400px] mx-auto px-6` 内栏；右列 `items-end`；收藏/评价/留言等交互；高 322、横排不折行。

**约束**：加大间距与红余量后，目视确认姓名/标签/统计背景落在白区；若仍压红，优先再加大 `ml-24`（不回退成缩小红区以致违背「分界右移」）。

---

## 4. 验收

1. 相对对齐版：红白界更靠右。  
2. 姓名/标签/统计不叠在红底上（在白区）。  
3. 姓名、头衔、咨询/曝光数字略大于现状。  
4. 底白装饰相对照片下方/分界，已同步右移。  
5. 右上操作与「给专家留言」右对齐仍成立。
