# 首页轮播图与平台优势区调整设计

## 背景

首页顶部轮播图需要从静态展示升级为自动轮播，并由后台“轮播图管理”分别维护每张轮播图的大图和两个按钮图片。轮播图上的顶部小字、H1 标题、描述不再由后台维护，也不再叠加显示在大图上。

平台优势红色区域需要承接原轮播图 H1 文案“找得到、信得过、价更优、+AI”，并删除现有描述小字与智能客服按钮。

## 范围

1. C 端首页顶部 Banner
   - 使用最多 3 张后台配置图进行自动轮播。
   - 保留左右切换按钮和分页点。
   - 移除轮播图文字遮罩中的顶部小字、H1、描述。
   - 在每张图相同位置叠加两个图片按钮：“立即咨询”和“查看专题”。
   - “立即咨询”继续打开客服弹窗。
   - “查看专题”暂时沿用当前专题链接。

2. 后台轮播图管理
   - 删除“顶部小字”“H1 标题”“描述”三个配置项。
   - 每张轮播图保留大图上传与地址维护。
   - 每张轮播图新增两个按钮图片上传与地址维护：立即咨询按钮图、查看专题按钮图。
   - 默认素材使用 `frontend/public/statics/images/banner改` 下的大图与按钮图。

3. 后端数据
   - 在 `recommended_resources` 增加两个明确字段：
     - `consult_button_image_url`
     - `topic_button_image_url`
   - 管理端新增/更新接口、管理端 VO、C 端公开 VO 都透出这两个字段。
   - 新增 Flyway 迁移后运行仓库规定的 Flyway 启动风险自检。

4. 平台优势红色区域
   - 左侧保留图标与“平台优势”字段。
   - 将 H1 文案“找得到、信得过、价更优、+AI”放在“平台优势”后面，并留出视觉间距。
   - 删除“大数据引擎实时筛选，极速匹配最适合您的讲师与课程”小字。
   - 删除“智能客服，AI智能匹配培训资源”按钮和其按钮文字。
   - 保留“发布需求”按钮。

## 数据流

后台上传图片后得到 OSS URL，保存到 `recommended_resources`。C 端首页通过 `/recommendations/public?slotCode=HOME_BANNER&limit=3` 获取轮播图大图和两个按钮图 URL，按 `sortOrder` 展示并自动轮播。

## 容错

如果后台未配置按钮图，C 端使用本地默认按钮素材。若后台接口不可用，首页继续使用本地 fallback 大图和按钮素材。

## 验证

1. 后端执行模块范围编译或测试。
2. 新增 Flyway 脚本后执行 `python data-trans/scripts/_validate_flyway_migration.py --version <N>`。
3. 前端执行对应包管理器校验：
   - `frontend`: `pnpm lint` 或必要时 `pnpm build`
   - `admin-frontend`: `bun lint`
4. 启动页面后检查首页自动轮播、按钮图位置、按钮点击行为、后台上传保存与回显。
