# 淘课网 v2 — 全局业务概述

## 1. 平台定位

淘课网是一个 **企业培训采购平台**，连接培训需求方（企业/个人）与培训资源供给方（讲师/机构），提供"资源展示 → 需求对接 → 价值转化 → 增值服务"的业务闭环。

## 2. 角色体系

| 角色 | 定位 | 核心行为 |
|------|------|----------|
| B端企业甲方 | 企业培训需求方，核心付费用户 | 检索资源、AI 匹配、发布需求、下单购买、评价反馈 |
| C端个人甲方 | 个人学习需求方，次要付费用户 | 检索课程、在线学习、报名公开课、评价 |
| 讲师 | 核心内容生产者 | 入驻认证、发布课程（在线课/公开课/内训课/版权课）、管理主页、查看收益 |
| 讲师经纪人 | 讲师资源中介 | 入驻认证、维护旗下讲师资源库、推荐讲师、对接需求 |
| 机构 | 专业培训服务运营方 | 入驻认证、发布课程、批量排课、管理师资团队、查看收益 |
| 前台客服 | 一线服务支撑 | 在线聊天接待、知识库检索、需求转接、机器人配合 |
| 后台客服 | 后端运营支撑 | 全维度审核、资料维护、比价、批量导入导出、数据统计 |
| 超级管理员 | 系统管理 | 用户管理、权限分配、系统设置、数据统计 |

## 3. 核心业务模块

### 3.1 用户与账号（User）

统一的多角色用户体系。支持手机号/邮箱/第三方登录，企业可多人注册独立账号，用户标签（企业采购/个人采购）关联折扣权限。

### 3.2 讲师（Trainer）

平台核心资源供给方。讲师入驻需审核认证，支持资质升级；个人主页含简介美化、案例自动萃取、精彩片段；可发布在线课、公开课、内训课、版权课。

### 3.3 讲师经纪人（Agent）

管理多个讲师的中介角色。维护讲师资源库，支持多格式文件上传（DOCX/PDF/PPT/JPG/PNG），按领域分类管理讲师，查看旗下讲师运营数据。

### 3.4 机构（Organization）

专业培训服务运营方。区分高校/非高校，非高校不公开联系方式。管理旗下师资团队，支持公开课批量排课（多城市/多时间），管理公开课状态（招生中/确认开课/已取消）。

### 3.5 课程（Course）

平台核心业务实体，涵盖四种类型：

- **在线课**：线上视频学习，支持章节试听、进度保存、笔记、单设备限制，有效期 1 年
- **线下公开课**：线下授课，支持多场次排课、报名管理、状态流转、团购折扣
- **内训课**：企业定制培训，与讲师强绑定，不开放平台直接报名，仅展示咨询
- **版权课**：版权认证课程，平台统一定价，版权标识展示

### 3.6 订单与支付（Order）

覆盖在线课和公开课的在线购买。支持公对公转账、微信/支付宝支付；订单管理、退款、发票申请、提现结算。内训课不走线上支付。

### 3.7 评价与反馈（Review）

统一的评价体系：对讲师/机构/课程进行星级评分+文字评价+图片反馈。评价需后台审核后展示。支持回复、申诉。问题反馈工单独立管理。

### 3.8 企业案例（Case）

展示真实企业培训案例，含量化效果数据。支持案例图片自动萃取、收藏分享。提供"定制类似方案"入口引流至需求发布。

### 3.9 培训需求（Demand）

企业发布定制培训需求（不对外公开），实时同步至客服工作台和外部业务系统。AI 智能匹配推荐讲师，按匹配度排序并标注理由。支持需求跟踪。

### 3.10 分类与标签（Category）

培训领域、行业类型的层级分类体系。标签库由平台维护+讲师自选。自定义核心字段（≤8字）同步至导入导出功能。热门搜索词自动抓取+人工管理。

### 3.11 消息通知（Message）

统一的消息中心：短信/微信/平台站内信。模板化配置，按事件触发（审核结果、开课提醒、需求同步失败等）。

### 3.12 内容管理（CMS）

首页内容运营：轮播图、热点课程、AI 匹配入口、智能机器人、资源推荐区、增值工具推荐区、热门搜索词、底部信息。各板块内容由后台客服配置管理。

### 3.13 客服系统（Customer Service）

前台客服工作台（在线聊天、知识库、需求转接）+ 后台客服工作台（审核、资料维护、比价、批量操作）。首页机器人支持多轮对话和人工接管。

### 3.14 充值与余额（Recharge）

账户充值（分档折扣：1000/5000/10000 元），充值后购买课程享折扣。余额明细、消费记录、退款记录。充值金额仅用于课程购买，不可提现。

### 3.15 权限管理与系统设置（Permission）

RBAC 角色权限体系，精细化到功能模块+操作类型。系统基础参数配置、第三方接口配置、自动清理规则、操作日志（存储 1 年，不可删除）。

## 4. 核心业务流程

```
企业/个人注册 → 检索资源 / AI智能匹配 → 查看详情 → 在线咨询(客服)
                                                          ↓
                                              发布需求 ←→ 下单购买
                                                 ↓           ↓
                                            客服对接      在线支付
                                                 ↓           ↓
                                            讲师匹配     课程学习/参加培训
                                                 ↓           ↓
                                            培训落地      评价反馈
```

## 5. 技术架构概要

- **后端**：Java 17 + Spring Boot 3.5 + Spring Data JPA + Spring Security + JWT
- **前端**：Next.js 14 + Tailwind CSS + shadcn-ui + next-intl
- **数据库**：MySQL 8.4
- **缓存**：Redis + Redisson
- **消息队列**：RabbitMQ
- **数据迁移**：Flyway
- **接口文档**：springdoc-openapi
