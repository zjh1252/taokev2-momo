# 淘课网管理后台 - 数据爬取功能实施计划

## Context

老板需求：在淘课网管理后台增加数据爬取功能，从外部培训网站爬取专家、课程、机构信息，经管理员审核后入库。当前为试点阶段，先跑通 **讲师宝 (jiangshi99.com)** 的专家数据 + **企学宝 (lmschina.net)** 的课程数据的完整链路。

**架构决策**：Python FastAPI 爬虫服务独立部署，通过 REST API + Webhook 与 Java 后端通信，爬取数据先进中间表待审核再入库。

---

## 整体架构

```
管理员浏览器 → admin-frontend (Next.js) → taoke-admin (Java Spring Boot)
                                                |
                                                |-- POST /crawl/jobs --> Python Crawler Service (FastAPI, :8100)
                                                |                              |
                                                |                              +-- Scrapling Spider 爬取目标网站
                                                |                              |
                                                |-- POST /internal/crawl/callback <-- Webhook 回调
                                                |
                                                v
                                          crawled_trainers / crawled_courses 中间表
                                                |
                                                v (管理员审核)
                                          approve → 复制到正式表 (user_trainers / courses)
```

## 实施步骤（13 个任务，预计 13 人天）

### 第一步：数据库迁移 (0.5d)

**文件**: `backend/taoke-app/src/main/resources/db/migration/`

新建 3 个 Flyway 迁移文件（从 V64 起编号）：

1. **V64__create_crawled_trainers.sql** — 爬取专家中间表
   - 核心字段对齐 `user_trainers` 表：name, teaching_name, avatar, title, gender, bio, intro, background, good_at, specialties, expertise_tags, teaching_style, experience_years, teaching_years, province_id, city_id, partial_clients
   - JSON 子数据字段：education_json, experience_json, honors_json, books_json, courses_json, cases_json, evaluation_json
   - 来源标识：source, source_url, source_trainer_id
   - 去重字段：dedup_status (0未检查/1无重复/2疑似重复/3确认重复), dedup_trainer_id, dedup_reason
   - 审核字段：review_status (0待审核/1已通过/2已驳回/3已入库), review_reject_reason, reviewed_at, imported_trainer_id
   - UNIQUE KEY uk_source_trainer(source, source_trainer_id)

2. **V65__create_crawled_courses.sql** — 爬取课程中间表
   - 核心字段对齐 `courses` 表：title, type, category_id, sub_category_id, cover_url, intro, summary, syllabus, audience, highlights, duration_days, total_hours, price, original_price, keywords
   - 额外字段：category_name_raw, trainer_name_raw, plans_json, evaluation_json, target_audience, learning_outcomes, services_json
   - 去重/审核字段同上
   - UNIQUE KEY uk_source_course(source, source_course_id)

3. **V66__create_crawl_jobs.sql** — 爬虫任务记录表
   - 字段：source, data_type, status, config_json, crawler_job_id, total_count, success_count, duplicate_count, error_count, error_message, started_at, finished_at, triggered_by

### 第二步：Java 后端 Entity + Repository (0.5d)

**目录**: `backend/taoke-admin/src/main/java/com/taoke/admin/`

新建文件：

### 第三步：Java 后端 DTO + Controller + Service (2d)

**DTO 文件** (`dto/crawl/`)：
- `CrawlSourceVO.java` — 数据源信息
- `CrawledTrainerVO.java` / `CrawledCourseVO.java` — 列表 VO
- `CrawledTrainerDetailVO.java` / `CrawledCourseDetailVO.java` — 详情 VO（解析 JSON 子数据）
- `CrawlJobVO.java` — 任务 VO
- `TriggerCrawlRequest.java` — 触发爬取请求 (source, dataType, config)
- `CrawlCallbackRequest.java` — 回调请求 (jobId, event, items[])
- `ImportTrainerRequest.java` / `ImportCourseRequest.java` — 导入时可选编辑
- `CrawledTrainerQuery.java` / `CrawledCourseQuery.java` — 查询条件

**Controller** (`controller/AdminCrawlController.java`)：
- `GET /admin/crawl/sources` — 数据源列表
- `POST /admin/crawl/jobs` — 触发爬取任务
- `GET /admin/crawl/jobs` — 任务列表
- `GET /admin/crawl/jobs/{id}` — 任务详情
- `PUT /admin/crawl/jobs/{id}/cancel` — 取消任务
- `GET /admin/crawl/trainers` — 爬取专家列表（支持 source/reviewStatus/dedupStatus 筛选）
- `GET /admin/crawl/trainers/{id}` — 爬取专家详情
- `POST /admin/crawl/trainers/{id}/import` — 审核通过并导入
- `PUT /admin/crawl/trainers/{id}/reject` — 驳回
- `GET /admin/crawl/courses` / `{id}` / `{id}/import` / `{id}/reject` — 课程同理
- `POST /internal/crawl/callback` — Python 服务回调（校验 X-Crawler-Token）

**Service** (`service/AdminCrawlService.java`)：
- `triggerJob()` — 调用 Python 服务 REST API 创建爬取任务
- `handleCallback()` — 接收回调，执行去重检查，写入中间表
- `importTrainer()` — 从中间表复制到正式表：
  1. 创建 User（系统自动注册，角色 TRAINER）
  2. 创建 Trainer（状态=草稿），映射所有字段
  3. 解析 JSON 子数据，创建 TrainerEducation/Honor/Book/Case
  4. 更新中间表状态
- `importCourse()` — 复制到 courses 表（状态=草稿），需管理员指定分类映射和关联讲师
- `checkDuplicate()` — 去重逻辑（见下方去重策略）

**Service** (`service/CrawlerClientService.java`)：
- 封装与 Python 服务的 HTTP 通信（使用 Spring Boot 3.5 RestClient）
- 方法：triggerCrawl, cancelCrawl, getStatus

**配置** (`application.yml`)：
```yaml
crawler:
  base-url: http://crawler-service:8100
  callback-url: http://taoke-admin:8080/internal/crawl/callback
  callback-token: ${CRAWLER_CALLBACK_TOKEN}
```

### 第四步：Python 爬虫服务骨架 (1d)

**目录**: `X:\spider-prj\crawler-service/`

```
crawler-service/
  main.py                    # FastAPI 入口
  config.py                  # 配置（Java 回调地址、token 等）
  requirements.txt           # scrapling, fastapi, uvicorn, httpx
  api/
    crawl_router.py          # REST API: /sources, /jobs, /jobs/{id}
  crawlers/
    base.py                  # BaseCrawler(Spider) 基类封装
    jiangshibao_trainer.py   # 讲师宝专家爬虫
    lmschina_course.py       # 企学宝课程爬虫
  services/
    job_manager.py           # 任务管理（并发控制、状态跟踪）
    callback_service.py      # Webhook 回调 Java 后端
  models/
    schemas.py               # Pydantic 模型
```

**核心设计**：
- BaseCrawler 继承 Scrapling Spider，封装通用逻辑（元数据注入、封禁检测）
- JobManager 管理任务生命周期，使用 stream() 实时获取爬取结果
- 每 10 条回调一次 Java 后端，完成后发送 complete 事件
- 支持任务取消（通过 checkpoint 机制）

### 第五步：讲师宝专家爬虫 (1.5d)

**文件**: `crawler-service/crawlers/jiangshibao_trainer.py`

- 继承 BaseCrawler
- start_urls 指向讲师宝讲师列表页
- parse() 解析列表页 → 翻页 + 进入详情页
- parse_detail() 提取专家字段：
  - name, title, avatar, bio, intro
  - teaching_style, experience_years, good_at, expertise_tags
  - education_json, honors_json, courses_json, cases_json 等
- 字段缺失时填"暂无"
- download_delay >= 1.5s，concurrent_requests = 2

**注意**：需要先手动访问 jiangshi99.com 分析实际 HTML 结构，确定 CSS 选择器。

### 第六步：企学宝课程爬虫 (1.5d)

**文件**: `crawler-service/crawlers/lmschina_course.py`

**技术挑战**：课程商城 (mall.lmschina.net) 是 Vue SPA，需特殊处理。

**爬取策略**：
- 优先尝试逆向 mall.lmschina.net 的 API 接口（检查 XHR 请求）
- 如 API 无法获取，使用 Scrapling 的 DynamicFetcher (Playwright) 渲染 SPA
- 主站 (www.lmschina.net/course/mall/) 有课程卡片可提取基础信息
- 课程详情需从商城 SPA 获取

提取字段：title, type, category_name_raw, cover_url, intro, summary, syllabus, audience, highlights, price, trainer_name_raw, plans_json 等

### 第七步：回调 + 去重 + 导入联调 (1.5d)

联调内容：
1. Python 服务 → Java 后端 Webhook 回调
2. 去重检查逻辑
3. 导入正式表逻辑
4. 错误处理和重试

**去重策略（三级）**：
1. **爬虫端**：Python 侧 source + source_trainer_id 本地缓存去重
2. **数据库约束**：UNIQUE KEY 防止同一来源重复入库
3. **跨源去重**：Java 后端按 name + city 精确匹配，或 name 模糊匹配，标记疑似重复

## 验证方案

### 第一步：启动 Python 爬虫服务

```bash
cd X:\spider-prj\crawler-service
conda activate common-ai
pip install -r requirements.txt
python main.py
```

启动后访问 http://localhost:8100/docs 查看 FastAPI Swagger 文档。

### 第二步：测试爬取讲师宝

```bash
# 在 Swagger UI 中调用 POST /api/crawl/jobs，请求体：
{
  "source": "jiangshibao",
  "data_type": "TRAINER",
  "max_items": 5
}
```

或用 curl：
```bash
curl -X POST http://localhost:8100/api/crawl/jobs \
  -H "Content-Type: application/json" \
  -d '{"source":"jiangshibao","data_type":"TRAINER","max_items":5}'
```

观察返回的 job_id，然后查询状态：
```bash
curl http://localhost:8100/api/crawl/jobs/{job_id}
```
